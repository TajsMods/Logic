# Logic

A Godot mod created with Mod Loader 7.0.0 and Godot 4.5.1.

## Installation

1. Download the latest release
2. Extract the mod files to your game's mods directory
3. Launch the game with the Mod Loader

## Development

This mod is built using:
- **Godot**: 4.5.1
- **Mod Loader**: 7.0.0

## Structure

- `manifest.json` - Mod metadata and compatibility information
- `mods/Logic/mod.gd` - Main mod script
- `project.godot` - Godot project configuration
